# Demo video script (target 75–90 seconds)

Record the screen with OBS, or Windows' built-in recorder (Win+Alt+R in Xbox Game Bar), at 1080p in a browser window. Speak naturally; you don't need to read word for word.

| Time | On screen | Say |
|---|---|---|
| 0:00–0:10 | Landing page hero | "I'm in the IIT Madras BS degree. There are over 30,000 of us across India, studying online, and we have no campus. Our groups are scattered across WhatsApp and Discord, and anything important gets buried." |
| 0:10–0:20 | Click **Sign up**. Show that a non-IITM email is rejected, then your real `@ds.study.iitm.ac.in` email being accepted | "So I built Quad. Only verified IITM BS students can join. Cognito checks your student email, and your batch is read from your roll number." |
| 0:20–0:35 | Explore → open a course community → Posts tab → like and comment | "Every course, hackathon, fest and city meetup gets a community. Posts stay visible instead of getting buried in chat." |
| 0:35–0:50 | Open **Group chat** in two windows side by side; send a message with a PDF and show it appear instantly in the other window | "Group chat is real-time over API Gateway WebSockets, and you can share notes and PDFs straight from the browser to S3." |
| 0:50–1:05 | Click **✨ Catch me up** → "Last 7 days" | "And the part I'm proudest of: missed 200 messages? Catch me up uses Amazon Bedrock to give you the highlights, deadlines, unanswered questions and files you need, in about 3 seconds." |
| 1:05–1:15 | Members tab → Message someone → DM | "You can DM any verified student, like a senior, a teammate or a classmate, without sharing your phone number." |
| 1:15–1:30 | Architecture diagram, then terminal with Claude Code + `aws sts get-caller-identity` + CloudTrail | "It's fully serverless on AWS and defined in CDK. I built and deployed it in about 24 hours with Claude Code connected to my AWS account. Every resource it created is in CloudTrail. Try it at the link below." |

Tips:
- Use the **demo account** in the second window for the real-time chat shot.
- Zoom the browser to 125% so text is readable.
- Upload to YouTube as **Unlisted** and put the link in the submission.
